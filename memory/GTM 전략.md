# BeatTheIce GTM 전략

## 1. 문서 목적

이 문서는 BeatTheIce가 초기 고객을 확보하고 반복 가능한 판매 방식을 찾기 위한 Go-To-Market 전략을 정의한다. 제품 방향과 범위는 `memory/기획 개요.md`를 최상위 기준으로 삼으며, 고객 조사로 검증되지 않은 내용은 확정 사실이 아닌 **가설**로 취급한다.

## 2. GTM 목표

초기 목표는 대규모 사용자 확보가 아니라 다음 세 가지를 검증하는 것이다.

1. 호스트가 참가자의 어색함과 소외 문제를 해결하기 위해 도구를 도입하는가.
2. 참가자가 별도 교육 없이 QR 교환과 미션에 실제로 참여하는가.
3. 호스트가 같은 형식의 다음 행사에서 다시 사용하거나 비용을 지불하는가.

### 6개월 목표 가설

| 구분 | 목표 |
| --- | ---: |
| 실제 운영 파일럿 | 30회 |
| 누적 참가자 | 1,000명 |
| 파일럿 완료 행사 비율 | 80% 이상 |
| 행사당 참가자 활성화율 | 70% 이상 |
| 호스트 재사용 의향 | 50% 이상 |
| 유료 전환 행사 | 10회 이상 |
| 반복 유료 호스트 | 3곳 이상 |

수치는 초기 운영 가설이며, 첫 10회 파일럿 결과를 기준으로 갱신한다.

## 3. 시장 진입 순서

### Beachhead: 20~100명 규모의 소셜·네트워킹 행사

첫 진입 시장은 참가자끼리 처음 만나는 비율이 높고, 호스트가 현장에서 프로그램을 직접 진행하며, 별도 엔터프라이즈 구매 절차 없이 도구를 시험할 수 있는 행사다.

- 대학 동아리 연합 행사, 새내기·신입 구성원 네트워킹
- 커뮤니티 밋업과 사이드 프로젝트 네트워킹
- 코리빙·게스트하우스·소셜 파티
- 소규모 기업 워크숍과 온보딩 행사

| 세그먼트 | 문제 강도 | 접근성 | 반복성 | 초기 우선순위 |
| --- | :---: | :---: | :---: | :---: |
| 커뮤니티·밋업 운영자 | 높음 | 높음 | 높음 | 1 |
| 대학 동아리·학생 행사 | 높음 | 높음 | 중간 | 2 |
| 소셜 파티·공간 운영자 | 높음 | 중간 | 높음 | 3 |
| 기업 HR·조직문화 담당자 | 높음 | 낮음 | 중간 | 4 |
| 웨딩·대형 축제 | 중간 | 낮음 | 낮음 | 후순위 |

기업 시장은 객단가가 높을 수 있지만 보안, 구매 승인, 커스터마이징 요구로 학습 속도가 느릴 수 있으므로 제품 안정성과 운영 레퍼런스를 확보한 뒤 진입한다.

## 4. 핵심 고객 정의

### 구매자: 행사 호스트 또는 운영자

- 한 달에 한 번 이상 사람을 모으거나 반복 행사를 기획한다.
- 참가자 간 어색함과 소외를 줄이기 위해 프로그램을 직접 준비한다.
- 진행 인력이 부족하고 현장 분위기를 수치로 파악하기 어렵다.
- 복잡한 설치보다 링크 또는 QR로 즉시 사용할 수 있는 도구를 선호한다.

### 사용자: 행사 참가자

- 다른 참가자와 자연스럽게 대화를 시작할 계기가 필요하다.
- 앱 설치나 긴 회원가입에는 저항이 있다.
- 재미, 보상, 새로운 인연과 행사 후 추억이 참여 동기가 된다.

### 초기 고객 제외 기준

- 10명 미만으로 디지털 도구 없이도 진행이 쉬운 모임
- 200명 이상으로 운영 안정성·보안·현장 지원이 먼저 필요한 행사
- 매칭·연애 성과 자체가 핵심인 데이팅 서비스
- 미성년자 대상이거나 익명 상호작용의 안전 정책을 충족하기 어려운 행사

## 5. 포지셔닝

> 처음 만난 사람이 많은 행사를 운영하는 호스트를 위해, BeatTheIce는 QR 프로필 교환과 실시간 미션으로 참가자의 다음 행동을 만들어 주는 모바일 행사 참여 도구다. 단순한 명함 교환이나 퀴즈 도구와 달리 대면 대화의 시작부터 현장 진행, 보상, 행사 후 기억까지 하나의 흐름으로 연결한다.

### 핵심 메시지

- 호스트: **“분위기를 감으로만 운영하지 말고, 모든 참가자에게 대화할 계기를 보내세요.”**
- 게스트: **“앱 설치 없이 QR을 열고, 오늘 만날 사람과 미션을 바로 시작하세요.”**
- 파트너: **“행사 만족도와 재방문을 높이는 참여 프로그램을 별도 개발 없이 추가하세요.”**

### 경쟁 대안과 차별점

| 기존 대안 | 한계 | BeatTheIce의 차별 가설 |
| --- | --- | --- |
| 종이 명찰·자기소개 | 정보는 보이지만 다음 행동을 만들기 어려움 | 프로필을 대화 소재와 행동 CTA로 연결 |
| 진행자 구두 게임 | 진행자 역량에 의존하고 참여 현황 추적이 어려움 | 실시간 미션 발행·제출·결과 확인 |
| 설문·퀴즈 도구 | 무대와 화면 중심, 참가자 간 교류가 약함 | P2P 만남과 현장 이동을 중심으로 설계 |
| 디지털 명함 | 연락처 교환에는 유용하지만 행사 흐름 제어가 없음 | 호스트 운영과 보상까지 한 파티 안에서 연결 |
| 메신저 단체방 | 정보가 섞이고 참여가 편중됨 | 현재 행동과 대상이 명확한 미션 제공 |

## 6. 핵심 가치 전달 순간

제품의 활성화 기준은 가입이나 파티 입장이 아니라 다음 경험이 발생한 시점이다.

- 호스트 활성화: `파티 생성 → 참가자 5명 이상 입장 → 첫 미션 발행 → 제출 1건 이상 확인`
- 게스트 활성화: `파티 입장 → 프로필 완료 → 다른 참가자 QR 1회 스캔 또는 미션 1회 제출`
- 행사 가치 실현: 참가자 다수가 최소 한 명의 새로운 상대와 상호작용하고, 교류가 특정 소수에게만 집중되지 않으며, 호스트가 다음 행사 복제를 원한다.

## 7. 획득 전략

### 1단계: Founder-led 파일럿

초기 10회는 팀이 직접 호스트를 모집하고 행사 전 설정, 현장 관찰, 종료 인터뷰까지 수행한다.

- 지인 네트워크와 대학·커뮤니티 운영자에게 1:1 제안
- “20~100명, 처음 만나는 참가자가 많은 행사”만 선별
- 무료 제공 조건으로 관찰, 인터뷰, 익명화된 사용 데이터 활용 동의 확보
- 행사마다 하나의 핵심 가설을 우선 검증

### 2단계: 레퍼런스 기반 직접 판매

- 실제 행사 사례를 참가율, 새로운 교류 상대 수, 호스트 운영 시간 절감 중심의 1페이지 사례로 제작
- 유사 커뮤니티 운영자에게 이메일·DM 아웃바운드
- 행사 운영 대행사, 공간, 게스트하우스와 공동 패키지 제안
- 호스트 추천으로 다음 행사 유입 시 행사 크레딧 제공

### 3단계: 셀프서브 성장

- 네트워킹, 신입 온보딩, 소셜 파티별 공개 미션 템플릿
- 행사 종료 화면에 다음 호스트용 `내 파티 만들기` CTA 제공
- 무료 행사 하단에 제한적인 BeatTheIce 브랜딩 노출
- 반복 호스트를 위한 파티 복제와 템플릿 저장

## 9. 파일럿 운영 패키지

### 행사 전

- 30분 호스트 인터뷰로 행사 목적, 참가자 구성, 성공 기준 확인
- 파티 생성과 미션 3개 공동 설정
- 참여 링크·현장 QR·진행자 큐시트 전달
- 개인정보 공개 범위와 사진 미션 동의 확인

### 행사 중

- 입장률과 프로필 완료율 확인
- 첫 15분 안에 QR 교환 또는 미션 발행
- 참여가 낮을 때 진행 멘트와 난이도 조정
- 오류, 이탈 지점, 참가자 반응 관찰

### 행사 후

- 24시간 안에 호스트 인터뷰
- 참가자 3문항 설문: 대화 도움, 재미, 재사용 의향
- 핵심 퍼널과 참여 편중 검토
- 다음 행사 예약 또는 유료 전환 제안

## 10. 출시 단계

### Phase 0: 문제 검증 — 1~10회

- 팀이 모든 행사를 직접 지원한다.
- 가입 최소화, 파티 입장, QR 교환, 미션의 사용성을 검증한다.
- 성공 기준: 7회 이상 정상 운영, 호스트 5명 이상 재사용 의향 표명.

### Phase 1: 유료성 검증 — 11~30회

- 행사 단위 가격을 제시하고 템플릿과 호스트 온보딩을 표준화한다.
- 성공 기준: 유료 행사 10회, 반복 유료 호스트 3곳, 중대한 현장 장애 5% 미만.

### Phase 2: 반복 판매 검증 — 31~100회

- 파트너 채널과 셀프서브 생성 흐름을 연다.
- 월 구독과 행사 단위 과금의 선호를 비교한다.
- 성공 기준: 신규 유료 행사의 30% 이상이 추천·파트너·인바운드에서 발생.

### Phase 3: 확장

- 기업 온보딩·워크숍용 관리 기능과 브랜드 커스터마이징 검증
- 반복 세그먼트별 템플릿과 운영 리포트 강화
- 해외 진출보다 국내 세그먼트 내 반복성과 수익성을 먼저 확보

## 11. 핵심 퍼널과 지표

### 호스트 퍼널

`리드 → 상담 → 파일럿 확정 → 파티 생성 → 정상 종료 → 재사용 → 유료 → 반복 유료`

| 단계 | 핵심 지표 |
| --- | --- |
| 획득 | 채널별 적격 리드 수, 상담 전환율 |
| 도입 | 상담→파일럿 전환율, 파티 생성 완료율, 설정 소요 시간 |
| 활성화 | 참가자 5명 이상 입장, 첫 미션 제출 발생률 |
| 행사 성과 | 참가자 활성화율, 서로 다른 교류 상대 수, 미션 제출률 |
| 유지 | 30·60·90일 내 다음 행사 생성률, 호스트 재사용률 |
| 수익 | 무료→유료 전환율, 행사당 매출, 반복 유료 호스트 수 |
| 품질 | 현장 장애율, 지원 요청 수, 행사 완료율 |

### 참가자 퍼널

`초대 링크 열기 → 파티 입장 → 프로필 완료 → 첫 상호작용 → 두 번째 상호작용 → 행사 후 피드백`

### 북극성 지표 후보

**행사당 활성 교류 게스트 비율**: 파티에 입장한 게스트 중 서로 다른 상대와 QR을 교환하거나 미션을 제출한 게스트의 비율.

단순 클릭보다 실제 교류에 가깝고 “누구도 소외되지 않는 파티”라는 제품 목적과 연결된다. QR 스캔이 실제 대화를 보장하지 않으므로 현장 관찰과 참가자 설문을 함께 사용한다.

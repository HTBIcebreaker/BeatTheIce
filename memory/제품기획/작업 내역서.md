# 작업 내역서

BeatTheIce 최상위 제품 기획 초안

## 2026-08-29 작업 내역

- 원격 저장소 `HTBIcebreaker/BeatTheIce`를 로컬에 클론했다.
- 기존 README와 `memory` 문서 구조를 확인했다.
- 기존 `memory/기획 개요.md`의 문서 운영 설명을 실제 제품 기획 개요로 개편했다.
- 제품 정의, 문제, 목표, 역할, 사용자 흐름, 기능, 화면, MVP, 제품 원칙, 성공 지표를 작성했다.
- 구현 전에 합의가 필요한 정책을 미결정 사항으로 분리했다.
- 게스트 경험을 단일 순차 흐름이 아닌 `P2P 프로필 교환·대화`와 `실시간 미션 수행`의 두 개 핵심 플로우로 정정했다.
- 최상위 기획을 기반으로 `memory/기능 정의서.md`를 작성했다.
- 역할별 권한, 파티·미션·제출 상태, 기능 ID, 상세 처리, 예외 조건과 완료 기준을 정의했다.
- MAIN 및 미션 제출 화면의 기능, 실시간 동기화 대상과 MVP 제외 범위를 명시했다.
- 기능 정의서 마지막에 4인 개발 분담안을 추가하고 담당 기능, 산출물, 완료 기준, 공통 선행 합의와 권장 병합 순서를 정의했다.
- 개발 조건을 4명·90분·Next.js 단일 프로젝트로 확정하고, 정식 MVP와 별도로 프로토타입 범위와 분담안을 추가했다.
- 90분 동안 시연할 두 핵심 플로우, 담당자별 완료 기준, 시간표, 구현 금지선과 발표 시나리오를 정의했다.
- `memory/기술계획서.md`를 추가해 Next.js 단일 프로젝트 구조, mock 상태, localStorage, BroadcastChannel, 컴포넌트 구조, 4인 파일 소유권과 폴백 전략을 정의했다.
- 4명이 서로 기다리지 않고 작업하도록 기능별 디렉터리, mock adapter, 공통 계약과 파일 소유권을 분리했다.
- 필연적인 교차 기능 연결은 `ALPHA-TODO`로 수집하고 별도 알파 통합 사이클에서 adapter 연결과 E2E 검증을 수행하도록 기술계획서를 보강했다.

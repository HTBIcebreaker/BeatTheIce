# 1인분 작업 내역서

## 담당

`1인분 — 앱 골격·MAIN·프로필`

## 2026-08-29 수행 내역

### 기존 구현 확인

- Next.js App Router 진입점과 모바일 최대 너비 Shell이 존재함을 확인했다.
- 홈, 미션, QR 스캔, 롤링 페이퍼, MY의 5탭 내비게이션과 각 진입점을 확인했다.
- 와이어프레임 기반 MAIN에 호스트 공지, 내 프로필·QR, 상대방 영역, 미션 CTA와 참가 현황이 배치되어 있음을 확인했다.

### 역할·사용자·탭 상태

- `src/features/shell-profile/preferences.js`를 추가했다.
- `currentUserId`, `isHostMode`, `activeTab`을 `beattheice-shell-profile` 키로 localStorage에 저장한다.
- 앱 시작 시 저장된 사용자, 역할과 탭 상태를 복원한다.
- 초기 복원 전에 기본값이 저장값을 덮어쓰지 않도록 복원 완료 상태를 분리했다.
- 데스크톱 hover에 의존하던 게스트 전환 메뉴를 모바일 클릭 방식으로 변경했다.
- 게스트 전환 시 HOST 모드를 해제하고 선택 메뉴를 닫는다.
- 모바일 Header에서도 현재 HOST/GUEST 역할 문구가 보이도록 수정했다.

### 프로필 표시·편집

- 기존 프로필 저장이 Context에 없는 `setGuests`를 호출하던 결함을 수정했다.
- `PATCH /api/guests/:id` 프로필 업데이트 API를 추가했다.
- 수정 가능한 필드를 제한하고 존재하지 않는 게스트는 404로 처리한다.
- `guest_updated` 실시간 이벤트와 `updateGuestProfile` Context adapter를 추가했다.
- 현재 사용자가 바뀌면 편집 폼도 해당 사용자 정보로 동기화한다.
- 저장 진행, 실패 메시지, 편집 취소 상태를 추가했다.
- MAIN 프로필 카드에 태그를 표시한다.
- HOST 모드의 MY 화면에 호스트 컨트롤 진입 버튼을 추가했다.

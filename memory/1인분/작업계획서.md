# 1인분 작업계획서

## 담당

`1인분 — 앱 골격·MAIN·프로필`

## 목표

팀 전체 기능을 담는 모바일 Shell과 5탭 내비게이션을 유지하면서 HOST/GUEST 역할 전환, 데모 사용자 전환, 내 프로필 표시·편집·저장 흐름을 완성한다.

## 담당 범위

- Next.js App Router 진입점과 모바일 Shell
- Header, MAIN, 하단 5탭 내비게이션
- HOST/GUEST 데모 역할 전환
- 데모 게스트 전환
- 내 프로필 카드와 QR
- 이름, MBTI, 소개, 직업, 태그와 대화 주제 편집
- 현재 사용자, 역할, 탭 상태의 브라우저 저장·복원
- 다른 담당 기능의 진입점 연결 유지

## 구현 계획

1. 기존 Shell, MAIN, Header, BottomNav와 프로필 화면의 완료 상태를 확인한다.
2. 프로필 편집이 실제 데이터 상태에 반영되지 않는 결함을 수정한다.
3. 프로필 업데이트 API와 실시간 갱신 이벤트를 제공한다.
4. `currentUserId`, `isHostMode`, `activeTab`을 localStorage에 저장하고 복원한다.
5. hover에 의존하던 사용자 전환을 모바일 클릭 방식으로 바꾼다.
6. MAIN 프로필 카드에 MBTI, 한 줄 소개와 태그를 표시한다.
7. HOST 모드에서 프로필 화면을 통해 호스트 컨트롤에 진입할 수 있게 한다.
8. 빌드, 프로필 저장 API와 localStorage adapter를 검증한다.

## 완료 기준

- 모바일 MAIN과 5개 탭이 렌더링된다.
- HOST/GUEST 역할 전환이 즉시 반영된다.
- 클릭으로 데모 게스트를 전환할 수 있다.
- MAIN과 MY에 QR, 이름, MBTI, 한 줄 소개, 태그가 표시된다.
- 프로필 편집 결과가 API와 현재 화면 상태에 반영된다.
- 새로고침 후 현재 사용자, 역할과 탭이 복원된다.
- QR, 미션, 롤링 페이퍼 진입점을 유지한다.
- 프로덕션 빌드와 API·저장 adapter 검증을 통과한다.

# BeatTheIce 비즈니스 모델

## 1. 문서 목적

이 문서는 BeatTheIce가 누구에게 어떤 가치를 제공하고, 어떤 단위로 과금하며, 지속 가능한 수익 구조를 만들 것인지에 대한 가설을 정의한다. 시장 가격과 지불 의사는 아직 검증되지 않았으므로 가격과 손익 수치는 **검증용 가설**이다.

## 2. 비즈니스 모델 요약

BeatTheIce는 참가자가 무료로 이용하고 행사 호스트가 비용을 부담하는 B2B2C 행사 운영 SaaS를 지향한다.

`호스트가 파티 생성·결제 → 게스트가 링크로 무료 참가 → 교류·미션 데이터 생성 → 호스트가 운영 성과 확인 → 다음 행사 재구매`

초기에는 사용 빈도가 불규칙한 고객을 위해 **행사 단위 과금**을 중심으로 판매하고, 반복 행사가 확인된 호스트에게 **월 구독**을 제안한다. 기업·대행사에는 브랜드와 관리 기능을 포함한 계약형 상품을 별도로 검증한다.

## 3. 고객과 가치 제안

| 고객 | 해결할 일 | 제공 가치 | 지불 이유 |

## 4. 가치 교환 구조

### 호스트가 얻는 가치

- 아이스브레이킹 프로그램 기획·준비 시간 절감
- 참가자 전체에게 동시에 행동 계기 제공
- 현장 참여 현황과 미션 결과 확인
- 행사별 미션과 설정 재사용
- 참가자의 만족·재사용 의향을 설명할 근거 확보

### 참가자가 얻는 가치

- 앱 설치 없이 빠른 입장
- 상대 프로필에서 즉시 사용할 대화 소재 확보
- 명확한 미션과 보상으로 참여 부담 감소
- 행사 종료 후 롤링 페이퍼와 긍정적 기억 보존

### 플랫폼이 얻는 가치

- 행사 이용료와 반복 구독 매출
- 재사용 가능한 행사 템플릿과 운영 노하우
- 참가자가 다음 호스트로 전환되는 제품 내 유입
- 파트너를 통한 반복 행사 공급

## 5. 수익 모델

### 5.1 무료 체험

- 최대 10명, 파티 1개
- 기본 미션 템플릿과 BeatTheIce 브랜딩
- 운영 리포트와 커스텀 기능 제외

무료 플랜이 유료 규모의 행사를 지속적으로 대체하지 않도록 참가자 수와 파티 수를 제한한다.

### 5.2 행사 패스 — 초기 주력

#### Starter Event: 49,000원 가설

- 행사 1회, 최대 50명
- QR 프로필, 실시간 공지·미션, 롤링 페이퍼
- 기본 템플릿과 행사 결과 요약
- 이메일·채팅 지원

#### Pro Event: 99,000원 가설

- 행사 1회, 최대 150명
- Starter 전체 기능
- 브랜드 컬러·로고
- 고급 미션 설정과 결과 내보내기
- 행사 전 설정 점검

행사 패스는 사용 시점이 명확해 구매가 쉽고, 초기에는 고객별 지원 비용을 가격에 반영하기 좋다.

### 5.3 호스트 구독 — 반복 고객용

#### Host Pro: 월 149,000원 가설

- 월 4회 행사, 행사당 최대 100명
- 파티 복제와 미션 템플릿 저장
- 운영 리포트와 데이터 내보내기
- 브랜드 설정
- 추가 행사는 별도 크레딧 구매

구독 전환 조건은 월 2회 이상 반복 개최 또는 최근 90일 내 3회 이상 결제다.

### 5.4 Business 계약 — 후순위

- 기업 온보딩, 조직 워크숍, 행사 대행사용
- 다중 관리자, 승인 절차, 참가자 데이터 보존 정책
- SSO·보안 문서·전용 브랜딩·현장 지원은 별도 견적
- 연간 계약 또는 행사 패키지와 최소 계약 금액 검증

제품 안정성과 개인정보·보안 체계가 준비되기 전에 엔터프라이즈 요구를 선행 개발하지 않는다.

### 5.5 부가 매출 후보

- 전문 진행자가 설계한 미션 템플릿 팩
- 현장 운영 지원과 행사 세팅 대행
- 화이트라벨·맞춤 브랜딩
- 행사 공간·F&B·경품 파트너 제휴 수수료
- SMS·대용량 이미지 보관 등 사용량 기반 옵션

광고 판매와 참가자 개인정보 판매는 핵심 경험과 신뢰를 훼손할 가능성이 높으므로 제외한다.

## 6. 가격 설계 원칙

- 참가자는 무료로 유지해 현장 입장 마찰을 최소화한다.
- 호스트가 예산을 잡기 쉬운 행사 단위를 기본 과금 단위로 삼는다.
- 참가자 초과 요금은 행사 직전 불안을 만들 수 있으므로 넉넉한 구간제로 제시한다.
- 유료 차별점은 핵심 교류 기능 차단보다 규모, 반복 운영, 브랜드, 리포트, 지원에 둔다.
- 가격 할인보다 다음 행사 크레딧을 사용해 재사용을 유도한다.
- 지원 시간이 긴 고객은 별도 운영비를 받는다.

## 7. 가격 검증 계획

### 검증할 질문

- 호스트는 행사 단위와 월 구독 중 무엇을 더 자연스럽게 받아들이는가.
- 49,000원과 99,000원 구간에서 구매를 막는 이유는 가격인가, 신뢰·기능 부족인가.
- 참가자 수와 기능 중 어떤 기준이 가격 공정성을 높이는가.
- 운영 리포트, 브랜딩, 현장 지원 중 실제 지불 기능은 무엇인가.

### 방법

1. 무료 파일럿 전에도 정상 가격을 먼저 보여 준다.
2. 종료 인터뷰에서 막연한 의향보다 다음 행사에 실제 견적을 제안한다.
3. 동일 세그먼트에 Starter·Pro를 함께 제시해 선택 이유를 기록한다.
4. 할인 없이 결제한 고객과 할인이 필요한 고객의 재구매를 구분한다.
5. 10건의 유료 제안 또는 5건의 실제 결제 전에는 가격을 확정하지 않는다.

## 9. 단위 경제성

### 기본 공식

- 행사 매출 = 행사 패스 가격 + 부가 옵션 매출 - 할인
- 행사 공헌이익 = 행사 매출 - 결제 수수료 - 행사별 인프라 - 행사별 지원 인건비 - 파트너 수수료
- 행사 공헌이익률 = 행사 공헌이익 ÷ 행사 매출
- 고객 획득비용(CAC) = 해당 기간 영업·마케팅 비용 ÷ 신규 유료 호스트 수
- 호스트 LTV = 평균 월 공헌이익 × 평균 유료 유지 개월
- CAC 회수 기간 = CAC ÷ 평균 월 공헌이익

### Starter Event 예시 가설

| 항목 | 금액 |
| --- | ---: |
| 행사 매출 | 49,000원 |
| 결제 수수료 | 1,500원 |
| 인프라·메시징 | 2,500원 |
| 원격 지원 30분 | 12,500원 |
| 행사 공헌이익 | 32,500원 |
| 공헌이익률 | 약 66% |

이는 의사결정 구조를 보여 주기 위한 예시다. 실제 인프라 청구액, 지원 시간, 내부 시간당 원가로 매월 다시 계산한다. 현장 방문이나 맞춤 미션 제작은 기본 가격에 포함하지 않는다.

### 목표 가드레일

- 셀프서브 행사 공헌이익률 70% 이상
- 지원 포함 행사 공헌이익률 50% 이상
- 반복 호스트 CAC 회수 3개월 이내
- 유료 호스트 90일 내 재구매율 40% 이상
- 한 행사당 수동 지원 30분 이하

목표를 지속적으로 밑돌면 가격 인상, 지원 범위 축소, 온보딩 자동화 중 하나를 실행한다.

## 11. 성장 루프

- 참가자→호스트: `행사 참가 → 가치 경험 → 내 파티 만들기 → 새 행사 → 신규 참가자 유입`
- 반복 호스트: `행사 종료 → 결과 확인 → 파티 복제 → 준비 시간 감소 → 더 자주 사용`
- 파트너: `공간·대행사 상품에 포함 → 반복 행사 공급 → 사례 축적 → 파트너 확대`

성장 루프가 초대 스팸이 되지 않도록 행사 종료 후 호스트 의향이 높은 사용자에게만 CTA를 노출한다.

## 12. 데이터와 신뢰 원칙

- 참가자 개인정보는 서비스 제공에 필요한 범위에서만 수집한다.
- QR에는 개인정보 원문 대신 만료 가능한 식별 값을 사용한다.
- 호스트 리포트는 개인의 민감 정보보다 집계된 참여 지표를 우선한다.
- 사진 미션은 목적, 공개 대상, 보관 기간을 사전에 알린다.
- 익명 롤링 페이퍼에도 신고·차단과 호스트 관리 정책을 둔다.
- 참가자 정보나 행동 데이터를 제3자 광고 목적으로 판매하지 않는다.
- 파티 종료 후 데이터 보존·삭제 정책을 상품별로 명확히 한다.

# 기획 개요

## 목적

BeatTheIce 프로젝트의 모든 LLM 판단과 작업이 공유 문서에 근거하도록 단일 진실 공급원(SOT)을 운영한다.

## 최상위 원칙

1. `memory` 폴더의 문서는 LLM 판단 및 작업의 최상위 SOT다.
2. 구현, 수정, 검토 결과가 `memory` 문서와 충돌하면 해당 작업은 잘못된 작업으로 간주한다.
3. 각 작업자는 작업을 시작하기 전에 관련 `memory` 문서를 확인한다.
4. 각 작업자는 작업 완료 후 결과가 `memory` 문서를 위배하지 않는지 점검한다.
5. 작업 과정과 결과는 담당 작업자의 폴더에 각각 작업계획서와 작업 내역서로 기록한다.
6. `runbook.md`가 제공되면 작업자는 이를 읽고 공유된 팀 스킬과 운영 절차를 적용한다.

## 문서 구조

- `memory/기획 개요.md`: 프로젝트 공통 기획과 최상위 원칙
- `memory/<작업자 이름>/작업계획서.md`: 작업자별 계획
- `memory/<작업자 이름>/작업 내역서.md`: 작업자별 수행 결과와 SOT 준수 점검

## 현재 상태

- 저장소가 로컬에 준비되었다.
- 현재 저장소에는 `runbook.md`가 없으며, 수신 또는 추가되는 즉시 읽고 본 문서 및 작업 문서와의 정합성을 재검토해야 한다.

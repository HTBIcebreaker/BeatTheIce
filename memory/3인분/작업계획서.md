# 3인분 작업계획서

## 담당

`3인분 — 호스트 메시지·미션·결과·보상`

## 목표

사진 인증을 포함한 `미션 발행 → 게스트 제출 → HOST 검수 → 결과 발표 → 보상 확인` 흐름을 다른 담당 기능에 의존하지 않고 시연 가능한 상태로 완성한다.

## 담당 기능

- `MISS-01` 미션 생성 및 발행
- `MISS-02` 텍스트·사진 미션 제출
- `MISS-03` HOST 제출 확인 및 승인·반려
- `MISS-04` 미션 결과 발표
- `REWD-01` 승인 대상 보상 발급 및 확인
- 일반·미션·결과 메시지 팝업 연동

## 구현 계획

1. 미션에 `TEXT`와 `PHOTO` 제출 형식을 추가한다.
2. 사진 촬영·선택 후 최대 1280px, JPEG 0.72 품질로 압축한다.
3. 게스트에게 제출 미리보기, 재촬영, 제출 대기, 승인, 반려·재제출 상태를 제공한다.
4. HOST에게 제출 목록, 사진·텍스트 확인, 승인·반려 기능을 제공한다.
5. 승인 시에만 포인트와 보상을 한 번 발급하고 결과 팝업을 전송한다.
6. 중복 제출, 사진 누락, 중복 판정을 서버에서 차단한다.
7. 실시간 이벤트로 제출과 판정 상태를 HOST·GUEST 화면에 반영한다.
8. Supabase adapter 교체가 필요한 지점은 `ALPHA-TODO`로 남긴다.

## 완료 기준

- HOST가 TEXT 또는 PHOTO 미션을 생성할 수 있다.
- GUEST가 지정 형식으로 미션을 제출할 수 있다.
- PHOTO 미션은 촬영·선택, 압축, 미리보기, 재촬영이 동작한다.
- HOST가 제출 증빙을 확인하고 승인 또는 반려할 수 있다.
- 승인 전에는 보상이 발급되지 않고 승인 후 한 번만 발급된다.
- 반려된 제출은 다시 제출할 수 있다.
- 결과 발표가 다른 메시지 유형과 구분되어 노출된다.
- 프로덕션 빌드와 API happy path·예외 검증을 통과한다.
